# Security

Earful runs locally on files the user already holds. The counting path makes no network calls, sends no telemetry, and holds no credentials. The tool takes no position on the sensitivity of the feedback it counts, and version 1 makes no promise to detect or redact personal information in item text. Custody of the input files is the control, and a corpus should be handled at the sensitivity of its contents.

To report a vulnerability, use the private reporting route on the GitHub repository if it is offered there, or open an issue describing the class of problem without including exploit detail or any real feedback data. Reports are read by the maintainer. There is no bug bounty and no hosted service to probe, and the binaries published from this repository are the only supported builds.

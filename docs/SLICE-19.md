# Slice 19. An index for the documents folder

The docs folder held twenty five documents and no map.
A new reader, human or agent, met a file list and no
order.

## What landed

- docs/README.md indexes the folder in reading order,
  the design documents, the evidence records, and the
  build slices with a clause each on what it holds.
- Every document named in the index exists in the folder,
  checked against the directory listing as it was written.

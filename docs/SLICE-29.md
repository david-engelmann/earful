# Slice 29. A landing guide for the stack

The stack audit checked the stack. Nothing yet gave
the landing itself a document, the order, the heads,
and the runs in one place a landing pass can execute
without reconstructing them from twenty five reports.

## What landed

- docs/LANDING.md lists the landing order for the
  twenty four slice branches, each with its head and
  the hosted run that gated it, read back from the
  repository's own branch list as the guide was written.
- It names the proof branch as the one to skip, the
  labelling branch as the one to land before the export
  example, and the closing check, main's tree matching
  the final branch's tree file for file.
- The documents index names it and gains its slice 29
  line, and the changelog records it.

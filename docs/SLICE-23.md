# Slice 23. A worked example of the export path

The first real run starts from an export in the contract
shape, and that path had no worked example. The folder
and labelling examples could not rehearse it.

## What landed

- examples/import holds a nine line synthetic export in
  the contract shape, ids in order, sources from the
  contract list, one line repeating another word for
  word, and a five theme taxonomy.
- Its README walks check-export and import and states
  the four reconciliation numbers and the counting
  outcome, crashes counted at three, four themes
  suppressed under the minimum support, one item
  untagged.
- A command line test runs the example on every build
  and asserts the reconciliation lines and the counts,
  so the example cannot drift from the tool.
- The main README and the changelog point at it, and the
  documents index gains its slice 23 line.

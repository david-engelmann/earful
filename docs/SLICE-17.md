# Slice 17. A changelog

The repository had no changelog. The slice documents are
the engineering record, and nothing gave a reader the
user facing account of what the tool gained and when.

## What landed

- CHANGELOG.md at the repository root. An unreleased
  section carries the getting started example and the
  release readiness work. The 0.1.0 section summarises
  the build across November 2026 in user terms, the three
  input shapes, verify, the audit and precision gate, the
  frozen labelling path, the export contract and importer,
  and the hardening slices.
- It states plainly that nothing has been published to a
  package index yet.

# Slice 24. A guide to writing a taxonomy

The taxonomy decides everything the report can say, and
nothing in the repository told a user how to write one.
The only guidance was the example files themselves.

## What landed

- docs/TAXONOMY.md covers the file shape and the kinds
  in use, whole token multi label matching and why it
  works that way, phrase choice from real items, the
  minimum support and suppression rule, the audit gate a
  default taxonomy must clear, and versioning.
- The design section of the documents index names it,
  the main README points at it from the taxonomy
  sentence, and the changelog records it.
